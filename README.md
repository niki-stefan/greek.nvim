# greek.nvim

A neovim plugin that makes typing greek characters easier using the latin alphabet. It uses neovim [nvim_buf_set_extmark](https://neovim.io/doc/user/api/#nvim_buf_set_extmark()) to conceal.

The syntax is `greek[LETTER]`. In the future I plan to also support diacritics. It supports both lowercase and uppercase letters, for lowercase use `greek[letter]` and for uppercase use `greek[Letter]`.
